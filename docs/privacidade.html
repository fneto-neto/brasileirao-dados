Política de privacidade — Brasileirão 2026 · dados

Este site só publica dados públicos de futebol (tabela, jogos e artilheiros do Brasileirão Série A 2026) em arquivos estáticos.

  • Não pedimos, não coletamos e não guardamos dados pessoais de quem usa os arquivos ou o assistente que os consulta.
  • Não há cadastro, login nem cookies.
  • O site é hospedado no GitHub Pages; o GitHub pode registrar acessos conforme a política dele.
  • Os dados esportivos vêm do Opta (Stats Perform).
